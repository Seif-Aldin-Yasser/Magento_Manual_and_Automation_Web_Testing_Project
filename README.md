## ⚙️ How to Run Automated Tests (Maven + TestNG)

### Step 1: Clone the Repo

```cmd
git clone https://github.com/Seif-Aldin-Yasser/Magento_Manual_and_Automation_Web_Testing_Project.git
```
```cmd
cd Magento_Manual_and_Automation_Web_Testing_Project
```
### Step 2: Install Dependencies

Make sure you have:
- Java 11 and Above
- Maven
- Chrome Browser
- Edge Browser
- Firefox Browser

Then run:

```cmd
mvn clean install
```

### Step 3: Execute Tests

```cmd
mvn test
```

### Step 4: View Test Report

After execution, view the default TestNG HTML report in:

```
test-output/index.html
```
